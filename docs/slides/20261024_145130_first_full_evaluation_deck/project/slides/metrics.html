Evaluation design · V_strict is the main metric of TREC RAG 2024 nugget evaluation

12

V_strict is the headline: only full support counts, only vital nuggets count. The other variants matter for robustness: A and A_strict ignore the vital/okay label, so a conclusion that holds under them does not depend on that label, which is the least reliable part of the nuggets. Contradiction rate captures wrong answers, which recall alone hides. All comparisons are paired by question. We report both a bootstrap interval and a permutation p-value, and a cluster bootstrap over the 48 chapters of the Q&A because questions in one chapter cite the same acts. We did not adjust p-values; the S1 to S2 comparison is the single pre-specified main test, and the variant comparisons are reported as secondary.
