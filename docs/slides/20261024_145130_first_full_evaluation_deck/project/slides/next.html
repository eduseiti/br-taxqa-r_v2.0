What remains before this becomes a paper. First, extend the ceiling audit to all questions with the 16k oracle, which is cheap. Second, run the 16k point, where S3 also retrieves more, to give H3 and H6 a fair second chance. Third, a human calibration sample, starting with the judge disagreements, and a tax-law expert’s review of the cause classes. Fourth, a second embedding model and another generator family for generality. Fifth, fix the oracle construction so it never drops cited articles. And finally release the v2.0 dataset with corpus, chunks, nuggets and scores so others can reuse the evaluation.
