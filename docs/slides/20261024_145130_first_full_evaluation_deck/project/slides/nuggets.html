Evaluation design · nugget protocol after TREC RAG 2024 (vital / okay, support-based recall) · example paraphrased in English

10

We follow the nugget evaluation of TREC RAG 2024, adapted to the domain. A strong model splits each official answer into self-contained facts, each labelled vital or okay; the prompt forces exact values, a temporal anchor (the tax year) and forbids updating values to later law. A rule-based validator checks that every value in a nugget appears in the gold answer and that every answer line is covered. Two auditors from other model families then flag errors, and flagged nuggets go back for at most two repair rounds before the set is frozen. The judge comes from a third family to avoid self-preference. The example nuggets are paraphrased in English; the real ones are in Portuguese. The nugget set was frozen on 21 October, before the full RAG generation.
