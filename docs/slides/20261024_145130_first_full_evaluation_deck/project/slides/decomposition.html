This decomposition is the mechanism result. Of 552 questions, the set of nuggets the context supports changes from S1 to S2 in only 73. Where it improves, answers improve; where it worsens, they get worse, as expected. But most of the overall S2 gain comes from the 479 questions where the context supports the same nuggets under both strategies. So S2 does not mainly bring new facts; it presents them in a form the generator uses better: smaller, focused units, and more of the cited provisions. The citation analysis agrees: answers cite more of the gold articles under S2. This also explains why the effect is bounded: segmentation changes form, not the content ceiling.
