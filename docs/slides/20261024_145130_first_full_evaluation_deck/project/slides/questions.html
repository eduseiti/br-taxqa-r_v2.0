Motivation and hypotheses

4

H2 is the main hypothesis and the one the design is powered for. H1 is a precondition: if S2 does not retrieve better, an answer gain would be hard to explain. H3 to H6 are mechanism hypotheses. The timing matters for reviewers: H3 to H6 were written down in the plan note of 23 October before any answer was scored, so the null results for them are not post hoc. H6 is an interaction, which needs far more data than a main effect; we said in advance it might stay inconclusive.
