The secondary strategies give null results. S3 adds grouping chunks, S2c and S4 add the caput’s first sentence to paragraph chunks. None of the differences is significant and the signs flip between generators. At 4k, S3 and S2 hold the gold equally often, so this is a fair test of whether explanatory grouping text helps the generator; it does not. One caveat for reviewers: 299 of the S3 contexts are identical to S2’s at 4k, which dilutes any S3 effect; the 16k point, where S3 also retrieves more, is planned. H6, the size interaction, shows no sign in the predicted direction, but an interaction needs far more data than we have, so we report it as not supported rather than as evidence of no effect.
