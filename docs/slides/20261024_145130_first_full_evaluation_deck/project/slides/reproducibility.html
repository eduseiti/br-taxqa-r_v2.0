For reviewers interested in replicating or extending this: the full pipeline, from nuggetization to scoring, cost about 184 dollars in LLM calls, tracked call by call in ledgers. The largest item is not generation but evaluation, which is typical of nugget-based RAG evaluation with an LLM judge. Every call is cached, so all tables can be regenerated for free, and every run carries a manifest with the code commit and configuration. Retrieval and its evaluation regenerate in about half a minute. The embedding endpoint cost is not included in this figure.
